# Bryton C. Kober — Professional Portfolio

A recruiter-focused portfolio for ecommerce, omnichannel, product-data, implementation, and digital-operations roles. Built with React and Vite and deployed through Vercel.

## Local development

1. Run `npm install`
2. Run `npm run dev`
3. Open `http://localhost:3000`

## Production

Run `npm run build`. Vercel publishes the generated `dist` directory and uses `vercel.json` to support the portfolio's client-side routes.
